# Проверка производительности

Для воспроизводимого сравнения зафиксируйте модель, прошивку, разрешение, версию приложения, число установленных приложений и режим интерфейса (общая сцена или нативная сетка Android). Сравнивайте сборки на одном устройстве с одинаковыми обоями и числом колонок.

На подключённом тестовом Android TV для замера холодного старта выполните несколько раз:

```sh
adb -s SERIAL shell am start -S -W -n com.gathin.tvhome/.MainActivity
```

Сохраните значения `TotalTime` и отдельно проверьте время до появления значков и реакции первой карточки на пульт. На обоих движках пролистайте несколько рядов с удержанием стрелки, откройте приложение, вернитесь и переставьте карточку. На LG повторите с Magic Remote сразу после обновления каталога.

Для сравнения публикуйте число прогонов, медиану и диапазон. Время запуска Activity и время готовности каталога измеряются отдельно. Браузерные тесты проверяют поведение общей сцены, для оценки скорости телевизора нужны замеры на самом устройстве.
