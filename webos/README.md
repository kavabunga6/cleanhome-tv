# CleanHome TV на LG webOS

Порт добавляет на LG экран запуска с сеткой приложений. Проверено на **LG 55NANO866NA** (SDK 5.6.2) и **LG 43UA73006LA** (SDK 10.3.2). Другие модели LG с приложением Developer Mode можно проверить этой же инструкцией. Для Android TV и Google TV используйте [инструкцию для APK с общим интерфейсом](../README.md#установка-общей-версии-на-android-tv).

## Установка готового IPK

Компьютер понадобится для установки и обновления самого CleanHome. После установки список приложений и значки обновляются на телевизоре.

1. На компьютере скачайте [CleanHome TV 0.4.5 для webOS](https://github.com/kavabunga6/cleanhome-tv/releases/download/tv-ui-4/dev.cleanhome.tv.webos_0.4.5_all.ipk). Подключите компьютер и телевизор к одной домашней сети.
2. На LG откройте магазин приложений, найдите **Developer Mode** и установите. Войдите под своей учётной записью LG Developer. Включите **Dev Mode Status** и дождитесь перезагрузки.
3. Снова откройте Developer Mode. Включите **Key Server** и запишите IP-адрес с экрана. Код **Passphrase** понадобится при привязке компьютера. [Инструкция LG по Developer Mode](https://webostv.developer.lge.com/develop/getting-started/developer-mode-app)
4. На компьютере с Node.js и npm установите webOS CLI и добавьте телевизор. [Установка CLI от LG](https://webostv.developer.lge.com/develop/tools/cli-installation)

   ```sh
   npm install -g @webos-tools/cli@3.2.6
   ares-config --profile tv
   ares-setup-device
   ```

   Выберите **add**, задайте имя `my-lg`, введите IP с экрана телевизора, порт `9922` и пользователя `prisoner`. Сохраните запись. Затем выполните команды ниже. На запрос первой введите Passphrase с экрана LG с учётом регистра. Вторая команда покажет сведения о подключённом телевизоре.

   ```sh
   ares-novacom --device my-lg --getkey
   ares-device --system-info --device my-lg
   ```

5. Откройте терминал в папке со скачанным IPK и выполните:

   ```sh
   ares-install --device my-lg dev.cleanhome.tv.webos_0.4.5_all.ipk
   ares-launch --device my-lg dev.cleanhome.tv.webos
   ```

## Первый запуск и каталог

Откройте **Приложения → Подключить каталог LG** и подтвердите на телевизоре запрос от **CleanHome TV**. Это отдельное разрешение на чтение каталога. До подтверждения CleanHome показывает установленные приложения, которые смог найти по известным идентификаторам.

После подтверждения CleanHome запрашивает у LG доступные приложения и их значки при запуске, при возвращении на экран и каждые 30 секунд, пока открыт. Для проверки сразу после установки или удаления приложения нажмите **Приложения → Обновить**. Последний полученный каталог и привязка хранятся на самом ТВ. Если LG снова запросит разрешение, повторите подключение в разделе «Приложения».

## Управление

| Задача | Действие |
| --- | --- |
| Открыть приложение | Выберите карточку стрелками или наведите указатель Magic Remote. Нажмите OK. Под выбранной карточкой указано, когда вы последний раз запускали приложение из CleanHome. |
| Изменить размер карточек | Откройте «Настройки → Сетка главного экрана». Стрелки меняют число плиток в ряду. «Авто» подбирает его по ширине экрана. OK на шкале или «Готово» сохраняет выбор, «Назад» отменяет. |
| Выбрать приложения для главной | В «Приложениях» выберите карточку, затем «Добавить на главную» или «Убрать с главной». Приложение остаётся в библиотеке. |
| Расставить карточки стрелками | На главной или в библиотеке удерживайте OK на карточке примерно полсекунды. Когда откроется «Порядок приложений», отпустите OK, переместите карточку стрелками и нажмите OK, чтобы положить её. В библиотеке также доступна кнопка «Изменить порядок». Повторите для других карточек и выберите «Готово». «Отмена» возвращает прежний порядок. |
| Перетащить указателем | Наведите указатель Magic Remote на карточку главной или библиотеки, удерживайте OK до появления сортировки, перетащите карточку и отпустите. Переместите остальные и нажмите «Готово». |
| Изменить формат часов | В «Настройки → Часы» выберите «Системные», «12 часов» или «24 часа». Текущее время рядом с переключателем показывает результат. Системный формат учитывает настройки часов и регион телевизора. [Служба настроек LG](https://webostv.developer.lge.com/develop/references/settings-service) |
| Выбрать вход или фон | «Источники» показывает доступные входы. В «Настройках» можно выбрать обои и включить смену фона. |
| Снова открыть CleanHome | На проверенном LG кнопка Home ведёт на системный экран webOS. Оттуда выберите CleanHome TV в списке приложений. |

## Обновление и удаление

Для обновления установите новый IPK поверх существующего через `ares-install --device my-lg <файл.ipk>`. Для удаления выполните `ares-install --device my-lg --remove dev.cleanhome.tv.webos`.

Проверяйте **Remain Session** в Developer Mode. До истечения срока сессию можно продлить кнопкой **Extend**. При отключении Developer Mode телевизор удаляет установленные через него приложения. [Срок сессии и условия отключения у LG](https://webostv.developer.lge.com/develop/getting-started/developer-mode-app)

## Сборка из исходников

Из корня репозитория на Windows в PowerShell выполните:

```powershell
npm install --prefix .lg-sdk @webos-tools/cli@3.2.6
npm ci --prefix webos/service
.\webos\build.ps1
```

Готовый IPK лежит в `webos/dist/`. В него входят интерфейс из `webos/app/`, служба каталога из `webos/service/`, обои и шрифты из Android-проекта. Служба получает каталог через локальное подключение к самому телевизору.

Для проверки интерфейса после сборки:

```powershell
npm install --prefix webos/tests --no-save playwright@1.65.1
.\webos\tests\node_modules\.bin\playwright.cmd install chromium
node webos/tests/smoke.cjs
```

Тест использует имитацию ответов LG и проверяет навигацию, запуск, изменение порядка, перетаскивание и перенос сохранённой главной со старых версий в 1920×1080 и 1280×720. Системное разрешение на чтение каталога проверяется на физическом LG.
